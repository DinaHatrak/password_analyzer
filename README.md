

# Password Analyzer  

## Description  
-A practical Python project that combines entropy math, NIST standards, and brute force estimation to evaluate the strength of your password.
---

## Project Structure  
- **project.py** →  main file to run the program.
- **analysis/** → handels entropy calculation and brute force time estimation. .  
- **src/** → Includes NIST compliance checks and security tools.  
- **tests/** →Unit tests to keep the code works correct and easy to update.  

---


The program will ask you to enter a password. After that, it will show a report with:  
- **Entropy Score** (measures randomness and complexity).  
- **NIST Compliance** (checks if the password follows NIST rules).  
- **Feedback** (suggestions to make the password stronger).  
- **Estimated Cracking Time** (shows how long brute force might take).  

---

## Key Features  
- Evaluates password strength using **mathematical entropy**.  
- Makes sure it follows NIST rules.  
- Shows how long brute force might take.
- Gives simple tips to make it stronger.
   Has tests to ensure everything works.
